## 수업 개요 (Course Overview)

![center h:300](img/00-raspberry-pi.png)

- **하드웨어 제어**: [라즈베리파이](https://en.wikipedia.org/wiki/Raspberry_Pi) 기반 **GPIO 제어** 및 다양한 센서·액추에이터 인터페이싱 실습
- **빌드 및 배포 자동화**: **크로스 컴파일, CMake, CI/CD** 파이프라인 등 실무 임베디드 소프트웨어 엔지니어링 프로세스 습득
- **응용 시스템 구축**: IoT·로보틱스·지능형 제어 시스템을 설계하고 구현할 수 있는 실무 역량 함양

## 선수과목 및 사전 지식 (Prerequisites)

### 권장 선수과목

- 논리회로및실습, 컴퓨터시스템구조, 임베디드시스템응용, 프로그래밍 관련 교과목

### 필수 사전 지식

- **프로그래밍**: C/C++ 기초 문법, 포인터 연산, 메모리 동적 할당 및 구조에 대한 이해
- **운영체제 및 환경**: Linux/UNIX 환경 기초 쉘(Shell) 명령어 및 터미널 환경 조작 경험
- **하드웨어 기초**: 디지털 논리 레벨(HIGH/LOW), 전압·전류·저항 등 기초 전자회로 지식

### 권장 사전 학습 자료

- [Basic Unix commands](https://www.youtube.com/watch?v=3DA1grSp4mU)
- [Basic Linux Navigation](https://www.youtube.com/watch?v=dzHscTzpAME)
- [The vi Text Editor - Basic Intro](https://www.youtube.com/watch?v=KtTjamPKMhw)

## 수업 형태 및 평가 방법 (Format and Assessment)

- **수업 방식**: 이론 강의 및 **3인 1조** 팀 실습·프로젝트 병행
- **평가 항목 및 반영 비율**

| 평가 항목 | 반영 비율 | 평가 세부 내용 |
| :-------- | :-------: | :------------- |
| **출석** | 10% | 총 수업일수의 1/4 이상 결석 시 성적과 무관하게 F 처리 |
| **중간고사** | 15% | 지필 평가 및 팀 프로젝트 제안서 평가 |
| **기말고사** | 25% | 팀 프로젝트 최종 결과 보고서 및 시연 평가 |
| **과제** | 50% | 주차별 실습 보고서 작성 및 제출 |

> **출결 규정 안내**
>
> - 총 수업일수의 1/4(약 8회) 초과 결석 시 학칙에 의거하여 **F 처리**
> - 유고 결석 등 공적인 사유는 증빙 서류 제출 시에 한하여 출결 정정 인정

## 실습 구성 (Lab Overview)

| 실습 번호 | 실습 주제 | 주요 내용 |
| :-------: | :-------- | :-------- |
| **01** | 크로스 컴파일 | 빌드 환경 구축 및 타깃 보드 배포 |
| **02** | 기본 입출력 및 PWM | LED, 택트 스위치, 소프트웨어 PWM, 상태 기계(FSM) |
| **03** | 기초 센서 인터페이싱 | 온습도(DHT11), 조도(CdS), 초음파 거리 센서 제어 |
| **04** | 센서 통합 웹 서버 | 센서 데이터 수집 및 실시간 경량 웹 서버 구축 |
| **05** | 오디오 입출력 | ALSA 라이브러리 기반 녹음 및 오디오 파형 시각화 |
| **06** | 카메라 영상 제어 | V4L2 기반 정지 영상 및 동영상 캡처 |
| **07** | 웹캠 기반 CCTV | 실시간 스트리밍 및 원격 모니터링 시스템 구현 |

- **실습 02~04**: 라즈베리파이 GPIO 및 하드웨어 버스 제어
- **실습 05~07**: 멀티미디어 인터페이스(오디오·영상) 통합 프로그래밍

## 조별 지급 교보재 (Lab Equipment)

- 교보재는 조 편성 완료 후 일괄 배부하며, **14주차 종강 시 전체 회수** 예정

| 분류 | 품목 | 기본 수량 | 활용 실습 |
| :--- | :--- | :-------: | :-------- |
| **컨트롤러** | Raspberry Pi 4/400(전원 어댑터, microSD 포함) | 1 set | 전체 실습 |
| **배선** | 브레드보드(Breadboard) | 1개 | 실습 01~06 |
| **배선** | 점퍼 케이블(M-M, M-F) | 1 set(20핀 이상) | 실습 01~06 |
| **출력** | 5mm LED(적/황/녹) | 3개 | 실습 01, 02, 04 |
| **입력** | 택트 스위치(Push Button) | 2개 | 실습 01, 02 |
| **센서** | 온습도 센서(DHT11, 1-Wire) | 1개 | 실습 03, 06 |
| **센서** | 조도 센서(CdS 포토레지스터) | 1개 | 실습 03, 04, 06 |
| **변환** | MCP3008 ADC(10-bit, SPI 통신) | 1개 | 실습 03, 04, 06 |
| **센서** | 초음파 센서(HC-SR04) | 1개 | 실습 03, 06 |
| **출력** | 피에조 부저(Buzzer) | 1개 | 실습 02, 06 |
| **영상·음성** | USB 웹캠(마이크 내장형) | 1개 | 실습 05~07 |

## 저항 소요량 (Resistors)

| 저항값 | 주요 용도 | 실습별 상세 소요 | 조별 지급 개수 |
| :----- | :-------- | :--------------- | :------------: |
| **330Ω**(또는 220Ω) | LED 전류 제한 | 01=3개, 02=2개, 04=1개 | 3개 |
| **10kΩ** | 스위치 풀업 / CdS 전압 분배 | 01=2개, 03=1개, 04=1개 | 2개 |
| **1kΩ** | HC-SR04 Echo 5V ➔ 3.3V 분압(R1) | 03=1개, 06=1개 | 1개 |
| **2kΩ** | HC-SR04 Echo 5V ➔ 3.3V 분압(R2) | 03=1개, 06=1개 | 1개 |

- 초음파 센서 Echo 신호 연결 시 5V 직접 인가 금지(반드시 1kΩ/2kΩ 전압 분압 적용)

### 실습 보고서 작성 기준

- **구성 체계**: 실습 목표 ➔ 회로 구성도 ➔ 핵심 소스 코드 ➔ 실행 결과 ➔ 고찰 순 작성
- **동작 검증**: **직접 촬영한 실행 사진 및 시연 영상** 첨부(조원 1인 이상 식별 가능하도록 촬영)
- **코드 설명**: 전체 코드 단순 복사 지양, **주요 로직 및 핵심 알고리즘만 발췌**하여 설명 기술
