## 수업 개요 (Cont'd - 1)

### 주요 용어 (Key Terms)

- **GPIO**(General-Purpose Input/Output): 프로그램이 입력 또는 출력 용도를 정하는 범용 디지털 핀
  - 예: 출력으로 설정한 핀에 HIGH(3.3V)를 쓰면 연결된 LED가 켜짐
- **크로스 컴파일**: 호스트(x86_64 PC)에서 다른 CPU의 타깃(라즈베리파이, AArch64)용 실행 파일을 만드는 빌드
  - 예: PC에서 `aarch64-linux-gnu-g++`로 빌드한 파일을 라즈베리파이에 복사해 실행
- **CMake**: 소스 목록과 빌드 옵션을 기술한 `CMakeLists.txt`로부터 Makefile 등의 빌드 스크립트를 생성하는 도구
- **CI/CD**(Continuous Integration/Continuous Delivery): 코드를 저장소에 올릴 때마다 빌드·테스트·배포를 자동으로 수행하는 방식
  - 예: GitHub Actions가 `git push`마다 크로스 컴파일과 테스트를 실행

## 실습 구성 (Cont'd - 1)

### 실습 주제 용어 (Lab Terms)

- **PWM**(Pulse Width Modulation): 일정 주기 안에서 HIGH 구간의 비율(듀티비)을 바꿔 평균 전력을 조절하는 방식
  - 예: 듀티비 50%로 LED를 구동하면 항상 켠 경우보다 어둡게 보임
- **소프트웨어 PWM**: 하드웨어 PWM 장치 대신 프로그램이 일정 시간마다 핀을 켜고 끄는 방식
- **상태 기계**(FSM, Finite State Machine): 현재 상태와 입력에 따라 다음 상태가 정해지는 제어 구조
  - 예: 버튼을 누를 때마다 신호등 LED가 녹 → 황 → 적 순서로 바뀜
- **ALSA**(Advanced Linux Sound Architecture): Linux 커널의 오디오 장치 인터페이스와 그 사용자 라이브러리 `libasound`
- **V4L2**(Video4Linux2): Linux 커널의 카메라·영상 캡처 장치 인터페이스, `/dev/video0` 같은 장치 파일로 접근

## 조별 지급 교보재 (Cont'd - 1)

### 부품 관련 용어 (Component Terms)

- **ADC**(Analog-to-Digital Converter): 아날로그 전압을 디지털 정수로 바꾸는 변환기
  - 라즈베리파이에는 아날로그 입력 핀이 없어 CdS 분압 전압을 직접 읽을 수 없음
  - MCP3008: 8채널, 입력 전압 0~$V_{REF}$를 0~1023(10비트) 값으로 변환
- **SPI**(Serial Peripheral Interface): SCLK·MOSI·MISO·CS 4개 신호선을 쓰는 동기식 직렬 버스
  - 예: 라즈베리파이가 MCP3008에 채널 번호를 보내고 변환 결과 10비트를 받음
- **DHT11 통신**: 데이터선 1개로 시작 신호와 40비트 측정 데이터를 주고받는 제조사 고유 방식
  - Dallas(Maxim)의 1-Wire 규격과 호환되지 않는 별도 방식

## 저항 소요량 (Resistors)

| 저항값 | 주요 용도 | 실습별 상세 소요 | 조별 지급 개수 |
| :----- | :-------- | :--------------- | :------------: |
| **330Ω**(또는 220Ω) | LED 전류 제한 | 01=3개, 02=2개, 04=1개 | 3개 |
| **10kΩ** | 스위치 풀업 / CdS 전압 분배 | 01=2개, 03=1개, 04=1개 | 2개 |
| **1kΩ** | HC-SR04 Echo 5V → 3.3V 분압(R1) | 03=1개, 06=1개 | 1개 |
| **2kΩ** | HC-SR04 Echo 5V → 3.3V 분압(R2) | 03=1개, 06=1개 | 1개 |

- **Echo 분압 이유**: 라즈베리파이 GPIO의 입력 전압 한계는 3.3V이며, 5V를 직접 연결하면 핀이 손상될 수 있음
- **분압 결과**: Echo(5V) → R1(1kΩ) → GPIO → R2(2kΩ) → GND 연결 시 GPIO 전압은 5V × 2/(1+2) ≈ 3.3V
